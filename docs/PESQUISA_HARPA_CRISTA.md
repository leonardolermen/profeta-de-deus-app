# Pesquisa sobre Harpa Cristã — 29/10/2026

Existe uma API comunitária em https://github.com/ronisdev/harpa-api, com consultas por número, título e estrofe. O repositório declara licença MIT e aponta um endpoint hospedado no Render. Não foi comprovada a disponibilidade contínua do serviço, a gratuidade futura ou autorização dos titulares para redistribuir as letras no aplicativo.

A licença do código da API não comprova, por si só, a licença de cada letra, tradução, adaptação, arranjo ou gravação. O aplicativo Bíblia JFA relata expressamente que não publica a Harpa por falta de autorização da CPAD: https://bibliajfa.com.br/faq-duvidas-frequentes.

O Ministério da Cultura explica as regras gerais de domínio público e uso de obras protegidas: https://www.gov.br/cultura/pt-br/assuntos/direitos-autorais/perguntas-frequentes/perguntas-frequentes. Não é suficiente presumir que todo o hinário está em domínio público pela idade de algumas músicas.

Conclusão da pesquisa: nenhuma opção foi verificada como atendendo simultaneamente a uso gratuito e permissão clara para redistribuir o catálogo inteiro. Não foi integrada a Harpa nesta versão. Para uma próxima etapa, obter autorização dos titulares ou selecionar obras individualmente com situação de direitos e origem documentadas; hospedar um catálogo próprio não elimina essa necessidade.
